# CAPD Streaming Checklists & Quick Reference

Practical checklists for smooth and professional streaming operations.

---

## 📋 Pre-Broadcast Setup Checklist

**30 Minutes Before Stream Start**

### Technical Setup
- [ ] Computer restarted (clear memory)
- [ ] OBS opened and tested
- [ ] Internet connection tested (speed >5 Mbps upload)
- [ ] Backup internet ready (mobile hotspot, 4G)
- [ ] Camera connected and focused
- [ ] Microphone connected and tested
- [ ] Audio levels checked and balanced
- [ ] OBS scenes configured and ready
- [ ] Stream key entered in OBS
- [ ] Bitrate set (4000 kbps recommended)
- [ ] Resolution set (720p recommended)
- [ ] FPS set (30 fps)
- [ ] Recording enabled (for archive)
- [ ] CPU usage checked (<50% idle)

### Graphics & Content
- [ ] Title graphics ready
- [ ] Transition graphics prepared
- [ ] Lower-third graphics loaded
- [ ] Closing screen ready
- [ ] Any video clips pre-loaded
- [ ] Music/audio tracks tested
- [ ] Captions/subtitles prepared (if applicable)

### Platform Setup
- [ ] YouTube/Twitch event created
- [ ] Title and description updated
- [ ] Thumbnail uploaded
- [ ] Category selected
- [ ] Privacy set to "Public"
- [ ] Scheduled time correct

### Admin Panel
- [ ] Program added to Schedule
- [ ] Channel status updated
- [ ] Stream URL correct in CAPD
- [ ] Announcement ready to post

### Environment
- [ ] Studio/broadcast area clean
- [ ] Lighting adjusted
- [ ] Background visible and appropriate
- [ ] No clutter in camera view
- [ ] Doors closed (minimize noise)
- [ ] Phones on silent
- [ ] No notifications set to pop up
- [ ] Temperature comfortable

### Communication
- [ ] Co-hosts/guests confirmed
- [ ] Contact info for backup ready
- [ ] Team notified of start time
- [ ] Audience notified (social media)
- [ ] Announcement posted to CAPD

## 🎬 Live Stream Monitoring Checklist

**During Broadcast - Check Every 5-10 Minutes**

### OBS Monitoring (Bottom-Left Stats)
- [ ] FPS: 30 (or configured setting)
- [ ] Dropped Frames: <5
- [ ] Bitrate: Stable at ~4000 kbps
- [ ] CPU Usage: <80%
- [ ] Encoding Time: <50% of frame time
- [ ] Memory Usage: <50% available

### Stream Quality
- [ ] Video sharp and clear
- [ ] No pixelation or artifacts
- [ ] Smooth motion (no stuttering)
- [ ] Colors accurate
- [ ] Text legible
- [ ] Audio clear and balanced
- [ ] No background noise
- [ ] No audio distortion

### Content Flow
- [ ] Time on schedule
- [ ] Content matches plan
- [ ] Transitions smooth
- [ ] Graphics appearing correctly
- [ ] Captions accurate (if used)
- [ ] No technical glitches
- [ ] Audio/video sync correct

### Audience Engagement
- [ ] Viewer count displayed
- [ ] Monitor peak viewers
- [ ] Check comments/questions
- [ ] Note engagement level
- [ ] Address audience where appropriate
- [ ] Respond to moderator alerts

### Platform Status
- [ ] Stream showing as LIVE
- [ ] Title displaying correctly
- [ ] Thumbnail visible
- [ ] Chat working (if enabled)
- [ ] Playback working for new viewers

### Emergency Status
- [ ] Backup internet ready
- [ ] Backup camera available
- [ ] Backup audio ready
- [ ] Emergency procedures reviewed
- [ ] Contact info accessible

**When Ending Broadcast**

### Final Broadcast
- [ ] Announce stream ending
- [ ] Thank viewers for watching
- [ ] Promote next broadcast date/time
- [ ] Ask for follows/subscriptions
- [ ] Provide social media links
- [ ] Say goodbye professionally

## ⚠️ Troubleshooting Quick Reference

### Audio Issues
**Problem:** No sound
- [ ] Check microphone connected
- [ ] Check microphone muted (unmute)
- [ ] Check OBS Audio Input level
- [ ] Check volume levels in Windows
- [ ] Try different microphone

**Problem:** Distorted audio
- [ ] Lower microphone input level in OBS
- [ ] Move microphone away from mouth
- [ ] Check for background noise
- [ ] Use noise gate in OBS

### Video Issues
**Problem:** Stream won't start
- [ ] Check internet connection
- [ ] Verify stream key correct
- [ ] Check firewall settings
- [ ] Restart OBS
- [ ] Try alternate server

**Problem:** Lagging/buffering
- [ ] Lower bitrate (try 3000 kbps)
- [ ] Reduce resolution to 720p
- [ ] Close background applications
- [ ] Check internet upload speed
- [ ] Move closer to router

### Platform Issues
**Problem:** YouTube stream not appearing
- [ ] Refresh page
- [ ] Check stream is actually running
- [ ] Verify event is "Live"
- [ ] Check account permissions
- [ ] Try alternate browser

**Problem:** Twitch stream not going live
- [ ] Verify stream key correct
- [ ] Check if channel is in broadcaster mode
- [ ] Verify account verified
- [ ] Restart OBS and reconnect
