🚀 QUICK START (3 STEPS):

  1. Install FFmpeg (stream converter)
     ├─ Windows: choco install ffmpeg
     ├─ Mac: brew install ffmpeg
     └─ Linux: sudo apt-get install ffmpeg

  2. Start servers
     └─ npm run both
        (or: npm start + npm run rtmp-server in separate terminals)

  3. Broadcast with OBS
     ├─ Server: rtmp://localhost:1935/live
     ├─ Key: mystream
     └─ Click "Start Streaming"

📞 TROUBLESHOOTING:

  Problem: "ffmpeg: command not found"
  └─ Solution: Install FFmpeg for your OS

  Problem: "Port 1935 already in use"
  └─ Solution: RTMP_PORT=1936 npm run rtmp-server

  Problem: "Cannot find module 'node-media-server'"
  └─ Solution: npm install

  Problem: Stream won't connect
  └─ Solution: Check RTMP server is running, firewall allows 1935

  Problem: HLS won't play
  └─ Solution: Check URL is correct, try different browser
