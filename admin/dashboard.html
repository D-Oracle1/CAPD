🔴 RTMP Configuration Guide

Stream URL Format:

rtmp://localhost:1935/live/stream_name

For Remote RTMP Server:

rtmp://your-server.com:1935/live/stream_name

OBS Setup:

  • Settings → Stream
  • Service: Custom...
  • Server: rtmp://your-server:1935/live
  • Stream Key: your_stream_name
  • Click "Start Streaming"

💡 Note: Make sure your RTMP server is running. Use npm run rtmp-server to start it.
